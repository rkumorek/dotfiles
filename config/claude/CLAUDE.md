## Session log
At the start of every session, read the newest file in ~/.claude/session-logs/.
Write to today's log at ~/.claude/session-logs/YYYY-MM-DD.md (create file and folder if missing).
Do not wait for me to end the session. Write after every finished piece of work,
after every decision, and whenever we switch task.
Every entry has four headings:
- What was done (commands, files, features)
- Decisions made (and why)
- Open threads (unfinished, pick up next time)
- Errors (what went wrong, how it was handled)
